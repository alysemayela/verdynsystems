# Verdyn Systems Website

A custom static website for Verdyn Systems.

## Files
- `index.html` — website structure/content
- `styles.css` — visual design/responsive layout
- `script.js` — mobile navigation

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload these three files.
3. In the repository, open Settings → Pages.
4. Select the `main` branch and root folder.
5. Publish.
6. Add your custom domain in the Pages settings.
7. At your domain registrar, configure the DNS records GitHub gives you.

## Before publishing
Change the quote email in `index.html`:
`contact@verdynsystems.com`

You can also replace the placeholder system/service content with your actual products and pricing.
